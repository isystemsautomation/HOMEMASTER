HomeMaster® ENM-223-R1 measures three-phase voltage and current for branch or main-panel monitoring. The ATM90E32AS front-end accepts external current-transformer secondaries and mains voltage inputs within the published range, reporting RMS values, active/reactive/apparent power, power factor, frequency, harmonic distortion, import/export energy and event flags for sags, overvoltage and phase loss.

Two SPDT relay outputs (3 A @ 250 VAC system rating) support tariff switching or alarm contacts with external protection. RS-485 Modbus RTU exposes the register map defined in the published ESPHome package for the current firmware release. USB-C WebConfig configures CT ratio, phase mapping, thresholds and communication settings stored in flash.

Logic supply is 24 V DC. Voltage measurement terminals are for qualified installation only; follow local rules for mains work inside the panel. The module is not a billing-grade meter.

Install CTs with correct orientation and phase assignment before energising. Use the published burden and PGA settings from WebConfig rather than guessing ratios. Keep voltage sense wiring fused and segregated from RS-485 inside the panel.

Export baseline register values after CT installation for future service comparisons. State in user documentation that the device monitors consumption but is not a utility meter.

Use with a Modbus master such as HomeMaster MiniPLC or MicroPLC; Home Assistant integration is via ESPHome modbus entities on the master. CE marked; EU DoC included. Do not reference UL, CSA or FCC certifications. Mount on DIN rail inside a qualified electrical panel. The pack includes the module datasheet and EU Declaration of Conformity for partner documentation.
